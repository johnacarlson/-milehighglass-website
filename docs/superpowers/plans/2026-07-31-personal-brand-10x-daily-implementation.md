# Personal Brand 10x/Day Content Strategy — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Set up infrastructure, establish workflows, and execute the first week of 10x/day Instagram content strategy for Jack Carlson personal brand with implicit Hawthorne funnel.

**Architecture:** Three-phase execution — (1) Infrastructure: Shopify, Notion, scheduling tools; (2) Workflow: Templates, assignments, editing pipeline; (3) First Week: Filming, editing, scheduling, tracking.

**Tech Stack:** Shopify (pre-order), Notion (content management), Meta Business Suite or Buffer (scheduling), CapCut AI or hired editor (editing).

## Global Constraints

- **Posting Cadence:** 10 posts/day, 70 posts/week, spread across 12-16 waking hours (roughly every 1.5-2 hours)
- **Content Mix:** 15-20 fitness/discipline, 15-20 business/learning, 10-15 Hawthorne lifestyle, 10-15 personal/momentum posts per week
- **Team:** Jack (creative direction), Lee (filmer), Marina (strategic input), Ambassador guests, Editor (batch edit or CapCut AI)
- **Weekly Workflow:** Monday-Friday filming, Saturday-Sunday batch edit + schedule
- **Quality Standard:** Authenticity > polish; phone camera acceptable; captions + hooks required; no hard-sell on Hawthorne
- **Primary Metric:** Follower growth + engagement rate (target 50K followers + 8-10% engagement in 60 days)
- **Secondary Metrics:** Shopify traffic, Hawthorne pre-orders, viral moments (50K+ views)
- **Shopify First Drop:** 20 sweatpants + 20 crewnecks, limited edition, ship date clearly stated, no restocking

### Task 4: Set Up Editor Solution

**Deliverable:** CapCut AI subscription active (or hire part-time editor) and editing templates/workflow documented.

**Files:**
- No code files (CapCut is a tool)

- [ ] **Step 1: Choose editor solution**

Option A: **CapCut AI (Freemium, $5-9/month for Pro)**
- AI-powered auto-editing (adds captions, colors, transitions automatically)
- Fast for batch processing
- 15-30 min to edit 70 clips with templates
- Best for high-volume, quick turnaround
- Limitation: Less creative control

Option B: **Hire Part-Time Editor ($500-1000/month)**
- More creative control and consistency
- Better for complex hooks and storytelling
- Requires more communication/feedback loop
- Best if quality > speed

For 10x/day at scale, **recommend CapCut AI** for speed + cost. Can hire editor later if needed.

Assume **CapCut AI** for this plan.

- [ ] **Step 2: Subscribe to CapCut Pro**

- Download CapCut app (mobile) or use CapCut desktop
- Sign up / log in
- Subscribe to CapCut Pro ($5-9/month)
- Enable auto-captions feature (AI generates captions from audio)
- Enable trending audio library access

- [ ] **Step 3: Create CapCut editing templates**

Create 4-5 templates (one per content pillar) with preset styles:

**Template 1: Fitness/Discipline**
- Color grading: High contrast, bold colors (orange/red accent)
- Font: Bold, modern (e.g., DM Sans)
- Transition: Quick cuts (0.5s)
- Music: Upbeat, motivational (or trending audio)
- Text placement: Top/bottom, aligned left or center

**Template 2: Business/Learning**
- Color grading: Professional, muted (blues/grays)
- Font: Clean, readable (e.g., Inter)
- Transition: Subtle fades
- Music: Subtle background or voiceover
- Text placement: Lower third, right-aligned

**Template 3: Hawthorne Lifestyle**
- Color grading: Moody, archive aesthetic (desaturated, warm)
- Font: Edgy, modern (e.g., Clash Display or similar)
- Transition: Smooth fades or analog glitch effects
- Music: Trending, hip-hop, ambient
- Text placement: Lower third, creative positioning

**Template 4: Personal/Momentum**
- Color grading: Warm, intimate (golden hour vibes)
- Font: Friendly, approachable (e.g., Comic Sans — joking, but warm)
- Transition: Quick cuts with pauses
- Music: Emotional, story-driven
- Text placement: Overlay on video, various positions

Save each template as a CapCut project so you can duplicate and reuse.

- [ ] **Step 4: Document editing workflow**

Create a Notion page: "Weekly Editing Workflow" with steps:

1. Dump all 70 raw clips into a folder (Google Drive or local storage)
2. Import raw clips into CapCut project
3. Sort clips by pillar
4. Apply appropriate template to each pillar batch
5. Add auto-captions (CapCut AI generates)
6. Review captions for accuracy (fix typos, trim for timing)
7. Add hooks/CTAs as text overlays on first 3 seconds
8. Add trending audio or background music (from CapCut library)
9. Export all 70 videos (resolution: 1080x1920 for Instagram Reels)
10. Save final videos to organized folder (date-named: "2026-08-04-Posts-Batch")
11. Upload finalized videos to Buffer/Meta Business Suite
12. Schedule posts for the week

Estimated time: 2-3 hours for 70 clips using templates.

- [ ] **Step 5: Test editing workflow with sample clips**

- Collect 5-10 raw clips (phone or B-roll)
- Follow workflow steps above
- Edit and export
- Post 2-3 test clips to Instagram (or schedule for later)
- Assess quality, timing, consistency
- Adjust templates/workflow if needed

**Checkpoint:** CapCut Pro active, templates created, workflow documented, and tested.
